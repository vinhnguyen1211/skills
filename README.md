# vinhnguyen1211-skills

Claude Code skills by vinhnguyen1211.

## Installation

Add the marketplace in Claude Code:

```
/plugin marketplace add vinhnguyen1211/skills
```

Then open `/plugin`, go to the **Discover** tab, and install the skills you want.

## Available skills

| Skill | Description |
|-------|-------------|
| [exploratory-work](skills/exploratory-work/SKILL.md) | Map territory and surface unknowns before implementing — produces a structured report instead of jumping to code |
